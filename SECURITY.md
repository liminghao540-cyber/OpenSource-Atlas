# Security Policy

## Scope

OpenSource Atlas currently reads public GitHub repository metadata. It does not require GitHub credentials and does not execute code from inspected repositories.

## Reporting a vulnerability

Please do not publish secrets, access tokens, or exploitable details in a public issue. Contact the repository owner through GitHub's private vulnerability reporting feature if it is enabled; otherwise, request a private contact channel before sharing sensitive details.

## Important limitations

The health score is not a security assessment. It does not scan source code, dependencies, releases, or known vulnerabilities. A high score must not be interpreted as evidence that a repository is safe.
