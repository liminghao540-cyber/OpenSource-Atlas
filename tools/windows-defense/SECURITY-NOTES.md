# Security and Privacy Notes

- This project is a defensive, local-only prototype.
- Review source code before execution, especially scripts run with elevated privileges.
- Reports can contain personal or operational information. Keep them private and redact them before sharing.
- Do not treat an unknown process, open port, or external IP address as proof of compromise.
- No automatic remediation is implemented in v0.1.
- Report suspected bugs through the repository issue tracker without attaching unredacted reports.
